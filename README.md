# JavaScript Backend Express Starter

`자바스크립트 백엔드 개발 시작하기` 과정의 초기 상태를 보존하는 복구·검증용 저장소입니다.

## 기본 수업 경로

수업에서는 이 저장소를 필수로 복제하지 않습니다. 강의자료의 `Express 프로젝트 기본 설정`에서 새 폴더를 만들고 `npm init -y`로 프로젝트를 직접 초기화한 뒤 하나의 Express 프로젝트를 순서대로 완성합니다.

## 이 저장소의 역할

이 저장소에는 초기 환경을 확인하는 `.nvmrc`, `.gitignore`와 안내 문서만 있습니다. 패키지와 애플리케이션 코드는 들어 있지 않으며, 수업의 빈 폴더 시작 상태를 복구하거나 검증할 때 사용합니다.
